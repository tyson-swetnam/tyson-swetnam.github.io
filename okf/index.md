# tyson-swetnam.github.io

This is the root of an [Open Knowledge Format (OKF) v0.2](https://github.com/GoogleCloudPlatform/knowledge-catalog/blob/main/okf/SPEC.md)
bundle describing the GitHub Pages sites published under
https://tyson-swetnam.github.io/ by Tyson Swetnam (University of Arizona).

All content on this origin, including every project sub-site listed below,
is open for agentic AI crawlers to read; see [/robots.txt](/robots.txt) for
the site-wide permissive policy. Each entry links to an OKF concept document
whose `resource` field is the live URL of the sub-site.
